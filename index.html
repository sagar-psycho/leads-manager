Frequently asked questions

What is Abra Zylo AI SEO Generator?

It is an AI-driven product SEO platform for generating and validating search metadata, product descriptions, SEO URLs, and supporting product content.

Can Abra Zylo generate meta titles and descriptions?

Yes. The portal generates meta title and meta description fields and validates them against built-in quality checks.

Can Abra Zylo improve only failed SEO fields?

Yes. The platform supports field-level regeneration so only the sections that need attention are improved.

Does Abra Zylo support Groq, Gemini and OpenRouter?

Yes. The existing app supports provider selection through the generator and settings modules.

Does Abra Zylo include an SEO audit tool?

Yes. The portal includes an SEO checker for page title, meta description, focus keyword, content, and URL context.

Can Abra Zylo analyze Google PageSpeed Insights?

Yes. The performance workflow uses Lighthouse and Core Web Vitals data from Google PageSpeed Insights.
